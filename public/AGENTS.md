# public/ — the client

Loaded beside the root `AGENTS.md` when work touches the static root, which is served at the
URL root. Pointers only; each script's own header carries its contract. Cap: 10 KB.

**The root seams this tree lives under:** script is mechanics and never a renderer
(`R_no_build_step`, `D_no_js_build_step`), and a feature that owns a slice of the page owns a
file, paired with the markup it renders from and naming its ids (`D_feature_owns_its_file`).
Extraction is earned: a fifteen-line `theme.js` would be ceremony.

## `js/`

- `app.js` — the composition root: the page's spine (one `EventSource` demultiplexed to every
  feature), the theme, the command dialogs, the `commands` map, and every feature's mount.
  Anything crossing a boundary goes through here, never through another feature's DOM.
- `composer.js` — `initComposer`: everything `#composer` does — buffer, auto-grow, slash
  palette, keyboard, `POST /messages`.
- `statusbar.js` — `initStatusBar`: `#status-bar` and its ■ — status frames, `POST /cancel`,
  and the intended model read back.
- `transcript.js` — `initTranscript`: `#transcript` — blocks upserted by id, dropped, emptied,
  the stick-to-bottom scroll, and which reasoning blocks are open.
- `conversations.js` — `initConversations`: the list and how a phone reaches it — `#sidebar`
  refresh, delete, mint, and the drawer (including the `matchMedia` half of the 40rem
  breakpoint).
- `dom.js` — generic DOM mechanics (`openDialog`, `cloneTemplate`, `el`) with **no app
  knowledge and no markup knowledge at all**; imported as an ES module.

The server-side half of this contract is checked from Ruby:
`spec/pikuri_web/client_contract_spec.rb` reads every script joined — globbed, never listed —
and asserts that every id, template, route, class and command name they hard-code still
exists on the server's side.

## The rest

- `style.css` — hand-written chat layout, two layouts off one 40rem breakpoint; block kinds
  mirror the TUI's visual language, and it owns the reasoning disclosure row. The only
  hand-edited file here that names a raw colour — the icons' plate comes baked in from
  `bin/regen-icons`.
- `images/kuri.svg` — the mascot: a **verbatim** copy of `../pikuri/assets/kuri.svg`,
  transparent and unplated; master artwork every icon beside it is rendered from.
- `images/favicon.svg`, `images/icon-{32,192,512}.png`, `images/icon-maskable-512.png`,
  `images/apple-touch-icon.png` — the plated set, all generated by `bin/regen-icons`; never
  hand-edited.
- `manifest.webmanifest` — the PWA manifest: name, standalone display, the three manifest
  icons. Needs {Web::App}'s `mime_type :webmanifest` to be parsed at all.
